# Our Private Diaries

A web application built for sharing private diary entries and memories.

Live URL at https://sakshamp30-oss.github.io/our-diary/

> **Note: Work in Progress**  
> Authentication features are currently under active development. At this stage, only Google Sign-In and Guest / Anonymous Mode are functional. Other login options are temporarily disabled.

## Status
* Google Authentication: Functional
* Guest / Anonymous Mode: Functional
* Email / Password and Social Logins: Under progress
